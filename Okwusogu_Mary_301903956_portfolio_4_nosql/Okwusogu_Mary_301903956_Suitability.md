For the BlitzFintech Portfolio 4 implementation, the model used was the Document-Oriented NoSQL Model, implemented using MongoDB.
- NoSQL Model: Document-based
- Database: MongoDB Atlas
- Database GUI: MongoDB Compass
- Data Format: BSON (JSON-like documents)
- Use Case: Customer profiles, KYC information, accounts, and financial transaction records.
The document model was selected because it supports flexible schemas, nested documents, and efficient retrieval of related customer information.
