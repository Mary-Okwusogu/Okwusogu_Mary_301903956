Baseline Query
=================
SELECT * FROM financial_transaction
WHERE transaction_status = 'POSTED'
  AND DATE(created_at) = '2026-02-27';



Optimised Query
=====================
SELECT *
FROM financial_transaction
WHERE transaction_status = 'POSTED'
  AND created_at >= '2026-02-27 00:00:00'
  AND created_at <  '2026-02-28 00:00:00';
